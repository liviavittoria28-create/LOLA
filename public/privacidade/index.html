Política de Privacidade

Última atualização: novembro de 2026

Esta política explica como a Lola trata dados pessoais, conforme a Lei Geral de Proteção de Dados (Lei 13.709/2018 — LGPD). Revise este texto com o seu contador ou advogado antes de publicar e complete os dados da empresa responsável.

Quem somos

A Lola é um sistema de gestão para profissionais da beleza. Contato: WhatsApp (11) 96282-2060.

Dados que tratamos

  • Da profissional (titular da conta): nome, nome do estabelecimento, e-mail, WhatsApp, cidade e dados de acesso.
  • Das clientes da profissional: os dados que a própria profissional cadastra — nome, telefone, data de nascimento, observações, histórico de atendimentos e ficha de anamnese (que pode conter dados de saúde).
  • Dados técnicos: registros de acesso necessários para segurança, como endereço IP e data do login.

Papéis

Em relação aos dados das clientes, a profissional é a controladora e a Lola é o operador: tratamos esses dados apenas para prestar o serviço, conforme as instruções da profissional. A ficha de anamnese registra o consentimento da cliente para o armazenamento dos dados de saúde.

Para que usamos

  • Fornecer o sistema (agenda, cadastros, financeiro, relatórios e confirmações pelo WhatsApp).
  • Atendimento, cobrança da assinatura e comunicação sobre a conta.
  • Segurança, prevenção de fraudes e cumprimento de obrigações legais.

Não vendemos dados e não os usamos para publicidade de terceiros.

Compartilhamento

Os dados ficam em provedores de hospedagem e banco de dados contratados para operar o serviço. O envio de confirmações pelo WhatsApp usa o número conectado pela própria profissional.

Segurança

  • Cada empresa acessa somente os próprios dados; o isolamento é validado no servidor.
  • Senhas guardadas com criptografia (hash) e sessões protegidas.
  • Conexão com HTTPS e cópias de segurança diárias.

Seus direitos

Você pode pedir acesso, correção, portabilidade e exclusão dos seus dados. A profissional pode baixar a qualquer momento uma cópia com todos os dados da conta em Mais → Baixar cópia de segurança. Para pedidos, fale conosco pelo WhatsApp.

Retenção

Mantemos os dados enquanto a conta estiver ativa. Após o cancelamento, os dados podem ser mantidos pelo prazo necessário para obrigações legais e depois são excluídos, salvo pedido de exclusão antecipada quando permitido.

Cookies

Usamos apenas um cookie essencial de sessão para manter você conectada. Não usamos cookies de publicidade.
